## 🇬🇧 English

### Overview
This project is an interactive educational website about the **Herero and Nama genocide (1904–1908)**. It is designed as a self-contained digital resource that allows users to explore the historical context, events, consequences, and legacy of the genocide without requiring external explanation.

### Objectives
- Present a clear and academically grounded overview  
- Provide an autonomous learning experience  
- Connect events, locations, documents, and data  
- Ensure transparency of sources and methodology (see the methodology page)

### Features
- **History** — Structured narrative  
- **Timeline** — Interactive chronology  
- **Map** — Geographic visualization  
- **Statistics** — Data visualizations  
- **Documents** — Historical sources  
- **Resources** — Bibliography  
- **Methodology** — Research explanation  

### Tech Stack/Tools
- Vercel
- Next.js  
- HTML / CSS / JavaScript  
- Chart.js  
- Leaflet
